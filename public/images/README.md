# Assets

Положи сюда изображения синицы:

- `bird.png` — обычная синица
- `bird-fat-1.png` … `bird-fat-4.png` — стадии толщины
- `bird-pop.png` — эффект при тапе (опционально)
- `skins/chekushka.png` — скин Чекушка
- `skins/melstroy.png` — скин Мелстрой
- `sounds/pop.mp3` — звук тапа

Рекомендуемый размер: 512×512 px, PNG с прозрачностью.
